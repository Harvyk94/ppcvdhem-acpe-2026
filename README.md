# PPCVD-HEM+

**Website:** https://harvyk94.github.io/ppcvdhem-acpe-2026/

Interactive ADE OFF and ADE ON comparison across 245 paired risk profiles, showing drug regimens, initiation ages, incremental QALYs and ICERs. The page includes the live application demonstration and a guide to the completed ADE results.

The live demonstration uses a separate synthetic example with 1,000 simulated people and ADE costs OFF. Its website inputs differ from the revised ADE v3 analysis. Use the full comparison grid for revised findings.

Static files are served from the root of the `codex/github-pages` branch. No server, credentials or patient data are required. Research simulation outputs remain conditional on the specified profiles and assumptions.

Poster files and editable presentation downloads are not part of this public website.
